# 📖 ReadWise Suite

A modern **React + TypeScript reading management application** designed with a component-driven architecture and a responsive UI.

## 🚀 Tech Stack

* **React 18 + TypeScript** — Frontend development
* **Vite** — Fast development & build tooling
* **Tailwind CSS** — Utility-first styling
* **shadcn/ui + Radix UI** — Accessible UI components
* **React Router** — Client-side routing
* **TanStack React Query** — Server-state management
* **Zustand** — Lightweight global state management
* **Zod + React Hook Form** — Form handling & validation
* **Recharts** — Data visualization
* **Vitest + Testing Library** — Unit/component testing
* **Playwright** — End-to-end testing

## 🏗️ Project Structure

```text
src/
├── components/    # Reusable UI components
├── hooks/         # Custom React hooks
├── lib/           # Utilities & shared logic
├── pages/         # Application pages
├── test/          # Test configuration & tests
├── App.tsx        # Application routing
├── main.tsx       # Entry point
└── index.css      # Global styles
```

## ⚡ Getting Started

```bash
git clone https://github.com/Ayushb690/read-wise-suite.git
cd read-wise-suite
npm install
npm run dev
```

## 🧪 Testing

```bash
npm run test
npm run test:watch
npm run lint
```

## 🏭 Production Build

```bash
npm run build
npm run preview
```
